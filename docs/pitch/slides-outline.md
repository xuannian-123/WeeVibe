# AI 局长 · 路演 PPT 大纲（v5，10 页）

## 视觉规范（与产品一致）

| 元素 | 用法 |
|---|---|
| 朱砂红 `#e2412e` | 印章、强调字、"成局"、关键数字 |
| 芥末黄 `#f2b530` | 次级高亮、"协调了 N 位朋友" |
| 暖米纸色（手机端底色） | 讲"人"的页面：痛点、产品 |
| 深夜大屏 `#14110f` + 奶油字 `#f3e7d3` | 讲"机器"的页面：Demo、决策、检验 |
| 字体 | 标题粗黑体；数字用产品里的 Space Grotesk |
| 装饰 | 贴纸式粗描边卡片、轻微旋转、点阵底纹；每页最多一个印章 |

节奏：米纸（人的为难）→ 深夜（局长怎么想）→ 米纸 + 印章收尾。

---

### P1 · 封面
- **标题**：AI 局长
- **一句话**：怎么说它都听得懂，尽量照顾到每一个人。
- **画面**：米纸底，"局长"套朱砂贴纸方块转 -6°，右上角"成局"印章。底部小字：Agent 赛道 · 团队名。

### P2 · 痛点：组织者怎么排都会委屈一个人
- **标题**：每个群都缺一个靠谱的组织者
- **一句话**：能听懂每个人的情况，替大家拍板，还不偏心。
- **画面**：部门群截图（自己做，不用真人头像），四个气泡分别圈出：八点门禁 / 七点半才下班 / 手头紧（没说出口，用虚线框）/ 想安静点。中间一个焦头烂额的组织者小人。

### P3 · 局长做的四件事
- **标题**：听懂 → 照顾到每个人 → 卡住了就去协调 → 定了还盯着
- **画面**：四张贴纸横排：💬 怎么说都行（私聊 / 按钮 / 截图 / 刷卡）· ⚖️ 三级准则拍板 · 🙋 私下协调最小的让步 · 🌦️ 天气 / 打烊 / 提醒。

### P4 · 现场 Demo
- **标题**：现在，评委就是这个部门的同事
- **画面**：只放一句"请看大屏"。**不放截图**。

### P5 · 听懂：一句话变成能算的需求
- **标题**：不用填表，局长听得懂
- **画面**：左边一个私聊气泡"我腿受伤了，不想走太远，而且不喝酒"，箭头指向右边两张需求卡：`身体 · 路上 ≤ 25 分钟 · 很在意` / `环境 · 不去以喝酒为主的地方 · 在意`。下方一行：硬约束（门禁、清真）一定回问"是硬性的吗？"——听错一条就会把人排除在外。角落小字：58 句真实说法理解测试集，真实大模型 58/58。

### P6 · 拍板：三级准则
- **标题**：先保底，再求好
- **画面**：三级台阶（深夜底）：① 照顾到的人最多（能来 + 硬约束满足 + 满意度 ≥ 50）→ ② 最吃亏的那个人损失最小（之前吃亏多的人权重更高）→ ③ 大家整体最满意。右侧一行朱砂字："同样的输入，一定得到同样的结论 · 一键复算"。

### P7 · 没有完美答案时：找最小的让步
- **标题**：不放弃最后那一个人
- **画面**：一条时间轴 18:30 / 19:00 / 19:30，每个时间下面都少一个头像（门禁的 / 加班的）。下方一个手机私聊卡片："19 点开始，你大约只能待 53 分钟，这样也来吗？" →「可以」→ 时间轴变成全员到齐。三条规则（小字）：只问能让一小步的人 · 硬约束绝不谈判 · 让过步的人下次少问。底部："群里只看到'局长私下协调了 1 位朋友'"。

### P8 · 定了以后：局长还在盯着
- **标题**：一份能照着做的决定书
- **画面**：左边群公告样例（结论 / 为什么 / 注意 · 每条带应对 / 备案）；右边时间轴：定局 → 前 1 天复查天气 → 前 3 小时出发提醒 + 带伞 → 门禁前 15 分钟私下提醒 → 散场夜归提醒。角落小字：实测高德数据，50 家火锅店 49 家有营业时间，不少 21:30 就打烊——以前的算法会把饭局排到打烊之后。

### P9 · 真实数据 + 可信
- **标题**：赛场里的真实局
- **画面**：上半部分 3 个大数字（来自 `/stats`）：【N】个真实局｜【N】位真实用户｜【N】% 主动说了私密情况。下半部分一行：隐私是前提 —— 200 组随机场景反事实检验，7 项，0 泄露（以 `/firewall` 实时结果为准）。
- **注意**：没有真实数字就整页换成用户原话，不许估。

### P10 · 结尾
- **标题**：好的组织者，不是挑一个大多数人满意的方案，而是不放弃最后那一个人。
- **画面**：深夜底，正中朱砂"成局"印章，下方产品二维码 + `/firewall` 二维码。
