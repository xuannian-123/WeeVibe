# AI 局长 · 路演 PPT 大纲（10 页）

## 视觉规范（与产品一致）

| 元素 | 用法 |
|---|---|
| 朱砂红 `#e2412e` | 印章、强调字、"成局"、关键数字 |
| 芥末黄 `#f2b530` | 公平中心、次级高亮、数字 |
| 暖米纸色（产品手机端底色） | 讲"人"和"痛点"的页面：痛点、产品流程、商业 |
| 深夜大屏 `#14110f` + 奶油字 `#f3e7d3` | 讲"机器"和"现场"的页面：Demo、技术、数据 |
| 字体 | 标题用粗黑体；数字用产品里的 Space Grotesk |
| 装饰 | 贴纸式粗描边卡片、轻微旋转、点阵底纹；每页最多一个印章，别贴满 |

节奏：米纸（人的问题）→ 深夜（机器的解法）→ 米纸（生意）→ 深夜 + 印章收尾。

---

### P1 · 封面
- **标题**：AI 局长
- **核心一句话**：一句话，局就组好了。
- **画面**：米纸底，左侧大标题，"局"字套朱砂红贴纸方块并转 -6°（照搬首页 hero），右上角一枚"成局"印章。底部一行小字：Agent 赛道 · 团队名。

### P2 · 痛点：群聊死于"都行"
- **标题**：每个群都有一个组不起来的局
- **核心一句话**：想组局的人输给的不是没人来，而是没人拍板。
- **画面**：一张仿微信的群聊截图（自己做，不用真人头像）：发起 → 一排"+1" → "几点？" "我搬城东了" "我不吃辣" → "都行" → 时间戳跳到第二天，群里在聊别的。最后的"都行"用朱砂红圈出来。

### P3 · 我们的解法：三步
- **标题**：说一句 → 甩进群 → 盖章
- **核心一句话**：发起人说一句话，朋友 10 秒填完，AI 把时间、地点、忌口一次算清。
- **画面**：三张贴纸卡横排（照搬首页"怎么玩"）：💬 说一句话 / 📲 甩进群 / 🔴 盖章成局。下面一行小字：H5 链接，微信里直接打开，不注册、不下载。

### P4 · 现场 Demo（切到真实大屏）
- **标题**：现在，评委就是这个群
- **核心一句话**：给评委组一个今晚的饭局。
- **画面**：这一页只放一个大二维码占位，或者一句"请看大屏"。翻到这页时操作手切到真实页面。**不放截图**。

### P5 · 公平中心
- **标题**：让离得最远的那个人，也不吃亏
- **核心一句话**：我们不取平均点，而是求最小包围圆——最远的人路程尽量短。
- **画面**：深夜底，同一组 5 个成员点画两遍。左图：平均点（灰色）和最远那个人之间的长线标红；右图：最小包围圆，圆心是金色 ◎，最远的几个人都落在圆上。底部小字：精确算法，结果确定，不靠随机。

### P6 · AI 分工：大模型听懂，代码拍板
- **标题**：大模型不选店
- **核心一句话**：大模型负责"听懂"和"说人话"，选哪家店由确定性代码打分。
- **画面**：一条横向流水线：一句话 →【大模型：解析需求 / 识别忌口】→【代码：选时间 → 公平中心 → 高德搜店 → 查通勤 → 打分】→【大模型：写推荐语】→ 投票 → 成局。中间的"代码"段用朱砂红框起来。右侧放一根 100 分堆叠条：最长通勤 45｜平均通勤 15｜预算 20｜评分 10｜品类与距离 10，下面一行红字"每个忌口冲突 −15"。角落小字：大模型 8 秒超时 → 自动降级规则；地图搜不到店就报错，不编店。

### P7 · 真实数据
- **标题**：72 小时，赛场里的真实局
- **核心一句话**：不算演示成员，只算真人。
- **画面**：深夜底，4 个大数字：【N】个真实局｜【N】位真实用户｜【N】个盖章成局｜中位填写【N】秒。下方一条按小时的入局曲线（来自 `/stats` 的 hourly）。右侧 1–2 条用户原话贴纸 + 群聊截图（打码）。
- **注意**：没有真实数字就整页换成用户原话，不许估。

### P8 · 商业模式
- **标题**：定局那一刻，就是一张到店订单
- **核心一句话**：我们知道几个人、几点、多少预算、去哪家——向商家导流抽佣。
- **画面**：米纸底，左边一张"成局卡"（时间 / 店名 / 人数 / 人均），右边一圈品类图标：餐厅、球馆、剧本杀、KTV、桌游。底部飞轮：每组一次局 → 链接进一个新群 → 新的发起人。市场规模用【市场规模 + 来源】占位。

### P9 · 为什么是现在 & 下一步
- **标题**：已经做到的 / 接下来要做的
- **核心一句话**：大模型让"一句话就能用"成为可能，我们先把闭环跑通了。
- **画面**：左右两栏。左"已上线"打勾：一句话解析、公平选店、忌口提示、有人退出自动重算、过半自动定局、日历提醒、AA。右"下一步"空框：商家端与预订、真实用户留存数据、更多城市。**右栏只写计划，不写成已完成。**

- **核心一句话**：群聊里最贵的，不是那顿饭，是那句"都行"。
