## 视觉规范（与产品一致）

| 元素 | 用法 |
|---|---|
| 朱砂红 `#e2412e` | 印章、强调字、"成局"、关键数字 |
| 芥末黄 `#f2b530` | "这局新认识"、次级高亮 |
| 暖米纸色（手机端底色） | 讲"人"的页面：痛点、产品、商业 |

### P1 · 封面
- **标题**：AI 局长
- **一句话**：半生不熟的时候，尴尬的事交给局长。
- **画面**：米纸底，"局长"套朱砂贴纸方块转 -6°（照搬首页），右上角"成局"印章。底部小字：Agent 赛道 · 团队名。

### P2 · 痛点：最尴尬的是半生不熟
- **标题**：熟人有群，陌生人不来，半生不熟的最难
- **一句话**：想熟起来，又什么都说不出口。
- **画面**：三栏横排。左"熟人"：群里一句话就定了 ✓；右"陌生人"：根本不会组局；中间"半生不熟"放大、朱砂框，列 5 个气泡：预算紧不好意思说 / 门禁早 / 只认识两个人 / 不想和 TA 一桌 / 第一轮好冷场。

### P3 · 局长管到哪
- **标题**：从"组不起来"到"熟起来"
- **一句话**：说不出口的话私下告诉局长，局长定局、排座、一轮一轮调。
- **画面**：一条时间轴，五个贴纸节点：🤫 私聊局长（预算 / 门禁 / 熟不熟）→ ⚖️ 局长拍板（可复核）→ 💺 局长排座（每桌留熟人）→ 😶 每轮私下反馈，换桌时调整 → 🤝 局后互选"聊得来"，下次还坐一起。

### P4 · 现场 Demo
- **标题**：现在，评委就是摄影社的新社员
- **画面**：只放一句"请看大屏"。翻到这页操作手切到真实大屏。**不放截图**。

### P5 · 排座是个优化问题
- **标题**：坐哪，是算出来的
- **一句话**：把"让半生不熟的人熟起来"写成带约束的多目标优化。
- **画面**：深夜底。左边公式卡：`max 新交流机会 + 共同兴趣 − 重复同桌 − 熟人抱团`，下面列约束（红字）："第一轮每人有熟人""电量低的人每轮有熟人""互选的人至少同桌一次""回避的人不同桌"。右边三轮座位的小示意（两拨人从分开到混在一起）。底部小字：社交高尔夫球手问题的变体 · 多起点 + 迭代局部搜索 · 每局密钥派生随机，可复算。

### P6 · 可否认的排座
- **标题**：座位用了你的秘密，但从座位推不出来
- **画面**：三张深夜卡片并排：
  - **双方取高**：两个头像之间的箭头，"你说一般 / TA 说挺熟 → 按挺熟算"，下面一行：对方说了熟，你标什么座位都一样。
  - **诱饵分组**：一张 3 轮座位网格，标出 4 对"从没同桌"的灰线，其中只有 1 对是真的要求（不标是哪对），"≤ 1/3"。
  - **藏不住就不执行**：只有一桌时，"有人提要求"和"没人提"两份结果用 `=` 连起来，"逐字节相同"。

### P7 · 不靠保证，靠检验
- **标题**：把两个人的秘密对调，公开内容一个字都不能变
- **画面**：深夜底，左边大数字"200 组随机场景 · 0 泄露"（以 `/firewall` 实时自检为准）。右边 7 行清单：交换检验 / 可否认缺席 / 字面检验 / 身份隔离 / 单向标记隐藏 / 单方面不可见 / 可否认回避。底部一行：方案和座位都能一键复算（HMAC 输入承诺 + 输出哈希）。

### P8 · 真实数据
- **标题**：赛场里的真实局
- **画面**：4 个大数字：【N】个真实局｜【N】位真实用户｜【N】% 主动说了私密约束｜中位填写【N】秒（来自 `/stats`）。
- **注意**：没有真实数字就整页换成用户原话，不许估。

### P9 · 商业 & 下一步
- **标题**：每年都在大量新生的半生不熟小团体
- **画面**：左栏"场景"：新生入学、社团纳新、新员工入职、项目组组建，下面一张"成局卡"（时间 / 店 / 人数 / 人均）= 到店订单。右栏两列："已上线"打勾（私聊 + 防火墙、门限成局、可复核拍板、局内编排、每轮反馈、圈子记忆、AA）；"下一步"空框（商家端与预订、留存数据、公司团建版）。**右栏只写计划，不写成已完成。**

- **标题**：半生不熟的时候，尴尬的事交给局长；熟起来，靠局长排的每一桌。
- **画面**：深夜底，正中朱砂"成局"印章，下方产品二维码 + `/firewall` 二维码。团队名一行小字。
