# WeeVibe 晨间交接清单

## 先看结论

**已连接既有演示配置；新增接口尚未确认部署。** 本包已本地构建公开云登录/云HTTP参数，不能因此宣称新功能后端全通；[连接与兼容表](existing-demo-connection.md)区分原接口和新增接口。

这是完整源码与当次小程序构建包，**不是全部需求、12张Issue或上线验收完成**。测试数量、独立审计和构建结果以包内本轮最终验收/冻结记录为准；不要用历史日志推断当前版本全部通过。

证据分层：生产函数/路由/客户端/React测试含数据库及微信替身；v23的50项真实云端loopback只验证未认证拒绝、缺配置和响应边界，不是认证业务成功。v24换主未重跑HTTP。当前新功能没有微信原生或真实PG业务并发验收；旧演示的历史真机通过不覆盖新包。

## 最小需要你的动作（不发明权限）

1. 已获准更新指定共享演示业务函数及其对应库，但必须先确认**对应目标库、可恢复备份与回退条件**；不另建或替换身份库，不触原登录函数、收费及正式发布。目标访问、备份或库归属不明时先停依赖步骤。获准的源码/DDL更新不等于允许任意测试数据写入。不是把旧演示API地址填进来就支持新接口。第9/10/11条本轮没有实库应用证据；源码回退不等于数据库回滚。
2. 由已获准操作者在微信开发者工具导入本包，并使用合法AppID/开发或体验资格验原生能力。同一手机切换两个获准微信即可，不重新要求两部手机；不默认访问你的电脑。
3. 如需真实地图或模型测试，确认使用的已有服务、调用额度和服务端安全配置方式。不要把密钥发聊天或放小程序；协调adapter尚未实现的部分不能仅用凭证补齐。
4. 已问的**最低人数变化核实策略**保持待答，不重复催问。严格群资格若没有可靠能力，是否改受邀名单/人工审核属于另一个明确产品选择，未获确认前仍关闭正式团建填写。
