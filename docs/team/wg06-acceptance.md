# WG06 管理权交接补齐

复用现有邀请、接受、拒绝、撤回界面与唯一管理者事务，不另建管理系统。

## 本次结果

接任资格以仍有 `joined` 参加记录、环节未取消且尚未结束为准；允许正在进行或保位待重新接受的环节。交接不代表接受新安排，原席位、安排接受版本及预订记录不改变。全部退出、全部结束或取消不授管理权。接受时在父活动锁内重新读取资格。

单份待接、无倒计时、本人处理、当前管理归属及版本复验、幂等、取消失效继续生效。接受后原管理者写操作失效；新管理者随后退出参加也不交还管理权。

## 验证与交接

本机全量 205 个文件、3988 项测试通过，类型检查、API 构建和演示配置小程序构建通过。新增隔离 PostgreSQL 六组验收，包含接受与撤回／取消各四轮真实并发；以本分支 CI 结果为实际数据库证据。仅使用本地地址、专用验收库名和合成身份，不连接共享环境。

未部署、未更新体验版，本轮真实微信交接流程未执行。维护者复核合并并部署匹配后端后，应在同机两个真实微信身份下核验邀请、拒绝／撤回、接受后管理入口和旧管理者权限。不得把离线 UI 或 fixture 视为手机验收。
