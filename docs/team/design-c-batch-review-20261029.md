## 产物性质

预览直接渲染当前小程序 React 展示组件；浏览器只替换 Taro 原生标签及布局测量适配器。页面中的地点、人物、活动、日期和消息均为明确示例。没有读取真实微信资料、定位或业务账号，没有向业务 API 发请求。

确认预览中的照片用于离线示意；真实小程序仍使用真实地点数据，照片缺失时显示缺省。原生头像选择、昵称建议、地图与权限操作，需在真实小程序核对，浏览器不会伪造成功结果。活动动物头像仍采用此前确认的 21 张新头像；“我的”中的示例个人照片不代表活动成员动物头像。

## 本批视觉复核修正

修正 `.c-ui button` 的通用重置覆盖“我的”头像圆角的问题，使用明确的 `.c-ui .c-identity-avatar` 圆角与裁切规则。已在正常、缺省及长昵称状态确认圆形边界。

审核画板的设备边框改为外侧描边，避免 0.8 倍预览把画面右缘裁掉数个像素；这仅影响审核工具，不改动已确认首页。审核意见输入区修正字体声明。
