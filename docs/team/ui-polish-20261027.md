# 四导航六项界面精修

2026-10-27。对应 Issue35、WG-12。维护者确认六项精修本轮一起完成，沿用 GO／灵感／消息／我的和已有产品方向。

## 本轮结果

| 项目 | 最终行为 |
|---|---|
| 导航与浏览连续性 | 四板块分别记住滚动位置；灵感保留搜索词、区域、分类、已验证结果和收藏视图；消息保留全部/待处理筛选。账号切换或退出清理相应缓存，城市改变重新建立地点浏览来源。仅保留本次页面会话，不写入永久存储，不自动重放查询或收藏操作。 |
| 顶部与图标 | 保留微信原生 WeeVibe 标题，去掉内容区重复品牌；城市入口、导航、场景、收藏、设置和关闭使用统一线性图标。图标由仓库脚本原创绘制并生成小型 PNG，无新增依赖或外部图片请求。 |
| 文字与留白 | 保留白底、薄荷绿、浅桃和淡紫配色；统一字号层级、灰字对比度、段落行高、区块留白及常用点击区域。 |
| 卡片 | 地点图片统一高度；长标题和推荐理由限制两行，详情显示完整标题；按钮对齐，地点元信息、活动状态、资料标签和圆角保持一致。无照片时仍明确显示占位，不伪造场地图片。 |
| 操作反馈 | 统一按下、选中与禁用状态；账号、消息、地点首次读取使用中性骨架；空态给出下一步。消息刷新显示进行状态并防重复，失败可重试，已读和业务处理仍分开。 |
| 弹层与适配 | 城市、三种创建入口、地点详情及隐私同意使用相同弹层结构；标题和关闭按钮固定，内容使用原生 ScrollView，保留遮罩关闭；按可用高度处理键盘及安全区，输入重绘后保留键盘距离，避免已缩小视口重复抬升。补充小屏长文本换行。 |

代码入口：`features/shell/polish.css`、`features/shell/use-tab-scroll.ts`、`components/sheet.tsx`、`components/ui-icon.tsx`、`scripts/generate-ui-icons.cjs`。样式从首页导航壳加载，未重写创建、筹备或活动详情流程。

## 验证与边界

- 本机全工程类型检查、14 个相关测试文件共 261 项、演示构建与实际产物门禁通过。新增检查覆盖浏览缓存来源切换、离开后迟到响应、消息筛选恢复及键盘布局。其余既有身份、隐私和权限断言保留。
- 微信开发工具实际四导航图标为 5 个；灵感真实高德搜索返回 10 个地点；切至“我的”再返回，滚动前后均为 360 像素，搜索词及结果保留。长地点详情内部可滚动，关闭始终可达；消息刷新完成后恢复可点，筛选跨板块保留，编辑资料仍有 11 个兴趣。
- 最终构建另行核对导航、消息筛选、城市弹层、资料编辑和截图，运行异常为 0。检查只读取已有记录及主动搜索，没有创建活动、修改资料/收藏/已读，也没有调用模型。键盘遮挡与缩小视口有离线布局证据；不同实体手机的键盘和小屏显示仍待试用反馈，不能写成全部真机通过。
- PR36 已完成的微信头像/昵称快捷填写、自定义入口、编辑项精简、兴趣更新及移除内置扫码均保留。微信后台隐私用途已保存，但 wx.getLocation 申请仍为审核中；本轮没有把开发工具回调成功当作手机定位授权通过。
- 没有 API、数据库、迁移、登录协议或活动规则变更，不需要因本次页面更新重新部署 API。不重复已有基础双微信业务验收；体验版和正式发布分别授权。
