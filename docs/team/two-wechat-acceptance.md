# WEEGO 双微信实际验收

2026-10-25。用户已授权推进此项。当前准备新版客户端和验收步骤，两个真实微信的完整结果仍待执行；已有自动测试、开发工具结果及单手机反馈不能代填本表。

## 准备

- 两部手机、两个不同微信，匿名记为A和B；不固定团队岗位。
- A是本场活动发起人/管理者，B是申请人。两人都须有当前测试入口的微信平台资格。
- 第二微信已由管理员添加查看开发版、查看体验版权限，用户确认登录成功。用户补充当前为同一手机切换两个微信，B未出现A旧活动；仅记录此现象，完整身份隔离与两部物理手机验收仍待执行。临时预览与体验版资格分别核实，不授予后台管理或发布权限。
- 当前客户端使用真实云登录、云HTTP和独立WEEGO数据库；不注入测试身份、不手写登录数据，不重置原AppSecret。
- 记录客户端源码提交、构建时间、入口种类、API部署版本（未知则写未记录）及两机系统/微信版本。名称调整不改变接口、数据库、会话键或活动权限。
- 本次创建的是测试活动，名称明确带“验收”，时间选在实际验收之后、尚未截止，地点注明“测试用途，不作实际邀约”。不要将测试信息当作真实订场。

## 记录与完成条件

本次范围是创建→申请→整体批准的两身份链路，不包括尚未实现的成局、退出、变更重接受或管理交接。通过后只更新WG-01/03/11对应验收项，不直接关闭整张任务。

记录时间、匿名操作者、每段操作前后人数、双方本人状态、提示原文、截图/录屏位置及复测版本。截图应避开联系人列表、个人身份和登录凭据；不收集OpenID、临时code、会话令牌、签名或数据库连接。公开记录不填写微信号和管理员扫码信息。

遇到权限、登录或写入结果不确定时，记录实际中断点与页面提示。优先使用原请求的恢复入口，不反复发起新请求或换测试身份绕过问题；未做的步骤保持待执行。
