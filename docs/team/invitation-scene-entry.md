# WG-08 A：公开 scene 入口解析（不生成二维码）

本片补活动页与首页扫码对公开 `scene` 的接线，**不是二维码 provider、真实报名码生成或微信扫码验收**。没有新表、迁移、身份模型或业务写入；原无 scene 的活动详情、原生分享处理器、申请审批和邀请保存流程继续沿用。

## scene 表示什么

scene 仅表示已存在的公开 `InvitationSource.id`：将合法 UUID 去连字符为32位小写十六进制。解析最多接收96字符，至多一次 URI 解码，得到严格32位hex后再用原 UUID 版本/variant 契约核验；大写hex可规范化。不去除 scene 空格，不把加号当空格，不接受双重编码、控制字符、非法长度或非法UUID。

这只是公开来源编号，不是用户ID、OpenID、登录会话、席位/群成员资格或管理凭证。编码函数不会创建来源，也不代表该来源真实存在；必须通过原公开邀请GET核对。来源未知或后端不支持，不猜成活动ID。

## 两条入口共用一条核验链

1. 首页扫码仍只接受本小程序内部固定活动路径。新 `pages/activity/index?scene=...` 分支只允许一个 scene 参数，不接任意host、fragment、重复/额外query或 id/invitation_id 混合；原 id 加可选 invitation_id 白名单分支的行为不变。
2. 直接进入活动页的 scene 参数经同一严格 codec 检查；scene 与其它页面参数混合时明确格式错误，不回退旧 id 入口。没有 scene 时仍挂原详情组件。
3. 包装器只读 `GET /api/v1/invitations/:invitationId`，不附加 bearer、不调用 `/me`、登录、邀请保存或任何 POST。游客也可核对原本公开的来源，不扩大已有读权限。
4. 按原严格 `InvitationSource` DTO 校验准确 invitation_id、canonical activity_id 和 `source_only:true`，只用这两个合法ID构造固定 `redirectTo` 目标。服务端的此 DTO **没有 revision 字段**，本片不伪造来源版本；跳到原详情后由原真实活动读取当前 revision/安排。不会转发标题、头像、原始错误或未知query。
5. 来源已取消仍可打开其当前活动详情查看取消状态，不意味着可报名。邀请人退出不擅自让原公开来源变成管理或成员权限；是否可参加继续由原业务接口决定。

## 失败、中断与身份

404 结构化“来源不存在”与 HTML/未知404/405 的接口版本问题区分；503、错误形状、错来源或非 source-only 响应不能当成功或零活动。未知服务器正文不原文显示。旧后端缺接口时提示核对，不假装二维码已解析成功。

首页原生扫码必须主动点击，同步锁重复触发。native 返回后、实际 navigateTo 前复验原会话、当前页面可见性、目标选择代次与操作归属；离页、换账号/目标、已观察到的 A→B→A 不把旧结果带到新页面。取消或失败释放自身锁，不自动重试，旧 finally 不释放新操作；已发导航不能保证撤回。

入口公开GET也绑定当前会话（包括游客）与单调页面/source代次。来源改动、隐藏/卸载/取消令旧GET后续redirect失效；单独身份变化停止并要求手动重试，返回页面不自动恢复旧请求。原生redirect已经发出时显示其不可保证撤回的边界。成功读取来源不自动登录、保存邀请或申请报名，旧401不清新账号会话。

## 实际验收层级与剩余项

本轮证据应包括旧 helper 不识 scene 的函数 before、原 v32 实际 Home/活动页的 scene 缺项 before 与普通 id 正向，以及实际组件/客户端/原公开 route/service 的合成传输、身份和数据库替身回归；最终计数、类型与构建以交付日志为准。首页另有旧扫码离页/会话切换晚导航及双击缺口的 before/fix 回归，不把错误的测试选择器或 harness 依赖错误记为产品缺陷。

没有真实微信扫码、相机/相册、云端请求、DB、付费或provider调用。二维码图片生成、access_token/云OpenAPI承载、图片响应校验和分享图嵌码仍未实现；体验版活动页存在性与扫码资格尚未核实，**不能仅填配置就宣称整张 WG-08 完成**。原分享图仍准确提示二维码不可用。

保持 `pnpm build:mini:demo` 与既定云目标编译门禁，不退回普通空API；后端接口是否部署仍按 [现有连接范围](existing-demo-connection.md) 逐项核验。真实补验允许同机切两个获准微信身份，不要求两部手机。

保留 v32 完整源码/dist 回退；这是入口代码回退，不回滚数据库/管理权/历史，也不能撤销已发送原生导航。相邻图片保存范围见 [无二维码分享图](activity-share-card-slice.md)。
