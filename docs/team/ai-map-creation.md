# AI 草稿与高德地点接入

2026-10-25。本轮属于 WG-02 与 WG-07，保留现有创建预览和确认发布，不关闭整张任务。

## 用户流程

创建页输入想法并明确选择日期，生成后查看各段建议和缺项。确认后填入可编辑表单；有已填内容时先确认替换，称呼保留，本人参加勾选清空。之后仍须补齐必要项、预览并确认发布。失败或超时保留原表单，不自动重试模型调用。

每段地点支持输入城市和关键词，通过已有高德服务端接口查询。选择后填入名称和地址，可在地图中查看；来源与查询日期在创建页展示。费用不从地点查询自动填入，也不据此标记已核实或已预订。手动修改地点或地址时清除旧地图关联。

当前数据库地点字段没有独立坐标列，本轮不做迁移。原名称、地址和 source_url 保存高德位置链接，坐标在链接内；本机草稿另保留 GCJ-02 坐标及来源。未将完整查询结果或密钥写入活动。

## 模型与配置

建议首轮使用 DeepSeek Flash，模型名 `deepseek-flash`，非思考模式与 JSON 输出。此为根据草稿整理任务作出的接入选择，尚无真实模型横测结果，不代表最佳效果或免费服务。后续时间协调另按实际样例评估，不在本轮实现发布后修改。

仅在 API 服务端配置以下变量，参照根目录 `.env.example`：

| 变量 | 内容 |
|---|---|
| AI_CHAT_COMPLETIONS_URL | `https://api.deepseek.com/chat/completions` |
| AI_MODEL | `deepseek-flash` |
| AI_API_KEY | 自有账号的 API 密钥，不进入源码、小程序或日志 |
| AMAP_WEB_SERVICE_KEY | 原有高德 Web 服务密钥，不是浏览器或小程序 SDK 密钥 |

服务端配置放在被 Git 忽略的 `apps/web/.env.local` 或独立演示 API 函数环境中。缺配置时明确提示，仍可手填；不自动充值、升级或借用其它项目凭据。小程序使用已有 Bearer 和原生 cloud-http，无需取得供应商密钥。

## 接口与边界

- 新增 `POST /api/v1/ai/creation-draft`：身份校验在先，输入为描述、明确日期和本次请求版本；只返回建议，无数据库写入。
- 高德继续使用 `POST /api/v1/venues/search`，复用已有 Provider。
- 描述最多1000字，最多8段，响应最多64KiB，模型调用25秒超时；仅此客户端请求延长至35秒，普通业务请求仍为10秒。
- 单进程每身份每分钟最多3次模型请求，不自动重试；不是全局配额保证，供应商账户预算仍需另行落实。
- 生成结果检查结构、引用、时间顺序、截止和人数关系。地点名称须出现在原文；模型 POI ID 不作真实地图记录。未明确表述的最低人数和上限留空。
- 现有 AI 契约未包含费用单位，因此草稿费用保持未知，由用户确认填写；不会把总价、小时价或模型输出的0当成人均或免费。
- 现有 `validateCreationDraft` 要求独立可信字段证据。本轮使用另一个明确返回未核实建议的边界，未把模型输出伪造为 known_fields 来绕过旧校验。
- 修改输入、切换身份、离开页面或表单锁定后，旧请求结果不得再填入。替换草稿前仍须明确确认，不自动选择本人参加。

实际微信开发工具已看到AI输入/生成入口和高德搜索入口并保存截图，已有本机草稿保留。构建后首次出现旧模块缓存白屏，仅清理该项目编译缓存并重开后恢复；未清理存储、身份或会话。该结果仅证明新增页面实际呈现，未验证真实模型成功或地图选点全流程。

用户补齐密钥后，本机服务端实际调用 DeepSeek Flash 已得到并通过两段草稿检查，覆盖主段、明确时间、人数及未定地点/费用。模型有一次将 unknowns 返回字符串数组；服务端现在自行重建缺项与待核实提示，不展示模型这部分自由文字，也不放宽活动字段校验。生成名为空时用各段名称组成可编辑标题。

高德初始 Key 实际返回 `USERKEY_PLAT_NOMATCH`，用户换为 Web 服务 Key 后本机真实查询返回2条上海地点及GCJ-02坐标，预订仍为未知。另一次真实模型缺信息样例正确保留未知时间、地点、人数和费用，且正确返回请求版本3。手机试用与更多效果样例继续，不能据此声称全面评估或最佳模型。
