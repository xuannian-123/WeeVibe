# 已取消安排的历史展示

本片只修现有 `cancelled_at` 数据的阅读方式，不增加单段取消入口，不改服务端、数据库、活动/安排/接受版本或问卷规则。原有整场取消仍按既定能力范围执行；取消非主段 writer 尚未实现。

## 显示语义

- 整场已取消，或本人某段已取消：原参加、原接受/未接受、退出及申请记录继续保留，但明确标为历史，不暗示当前有效席位或同意继续参加。取消不是系统替本人退出。
- 行程保留原场地、时间、费用及核实/预订记录；取消部分不再宣传“余位、满员、达到最低、需要重新接受”。原核实/预订属于原安排，不表示已退订、已退款或新安排有效。
- 本人 B1 审阅保留原版本与可信历史能力，已取消时显示历史接受语义。已发送未知请求仍可按原 key 核对当前结果；返回已取消当前快照，不应再被解读为“本人已接受当前有效安排”。新重新接受仍由原后端取消检查拒绝。
- 未取消的其他环节继续原显示。此显示分离不证明另一环节实际上不受费用/转场/要求变化影响，不替代正式变更分析。
- 未添加公开取消历史名单、他人资料或新的权限读取。现有公开名单对取消部分仍明确“历史暂不展示”，不是零人。
