## 本轮继续处理的问题

交接站内消息原来仅按邀请 ID 保存已读状态。已读的待接邀请后来被接受、拒绝、撤回时，结果可能继续显示已读，且时间停留在创建时。本轮将结果状态纳入消息标识，用处理时间排序，并将取消、管理归属或管理任期不匹配的待接消息显示为失效。已生效交接不会因后来取消退回。
