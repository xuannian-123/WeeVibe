## 本轮结果

管理统计增加“AI 协调前核对”。关联正式朋友活动时，管理者主动点击后经现有会话和传输读取协调汇总；不自动轮询，不调用模型或写业务数据。

区分有效填写人数、实际占位人数、跨环节席位、填写但未占位、占位但未填写，以及逐段意向/占位/已接受/待接受；已取消环节标为历史记录。显示服务器核对时间及服务端限制，不将自由文字当作已满足的硬约束，不将意向或需求定案当作报名成功或成局。

团建和未关联正式活动的独立筹备保留人工统计及定案路径，明确协调暂不可用。现有独立筹备定案→带入正式活动→预览发布、选段报名→管理者审批、安排重新接受和明确成局入口继续沿用，未重写业务规则。

协调响应按现有共享 schema 校验，并核对 collection/activity 身份。失败清除旧核对结果并允许重试；换号、父级资料刷新和卸载使在途结果失效；同次读取防重复点击。唯一公共层调整是 `platform/extension-api.ts` 增加精确 UUID 路径的协调 **GET** 白名单；POST/PUT/PATCH 仍被拒绝，不新增应用或绕过权限的通道。请平台维护者在 PR 中重点复核此处。
