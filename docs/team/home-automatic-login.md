# GO 首页与自动登录

2026-10-27，基于已集成的 v38。保留 GO／灵感／消息／我的导航及原三种创建路径。

首页内容依次为：品牌与城市/扫码入口；「下一站，和朋友一起」及发起按钮；熟人出游和团建入口；AI 创建草稿能力简述及灵感入口；本人待处理事项、活动与已保存邀请；手动打开活动入口。熟人出游打开既有选择面板，可以直接创建明确安排，也可以先筹备收集需求；团建直接进入既有团建流程。AI 介绍仅说明已实现的创建草稿，不宣称多人智能协调已接通。

首页进入/返回前台及各页面 requireUser 使用统一的自动身份读取：有效会话先向服务端核验；没有会话或明确 UNAUTHENTICATED 时通过原 code/cloud 适配器恢复，再核验身份。并发读取共享一次恢复尝试；网络、权限或配置错误不会触发无限重登，不自动重放创建、报名、批准等写入，也不触发搜索或定位。保留手动微信登录重试。

主动退出在本机持久化暂停标记并移除会话；重新打开仍保持退出，显式登录成功后恢复自动登录。请求携带原会话和代次守卫；退出、换会话后，迟回的自动登录不得覆盖新会话。活动/草稿/幂等键不变。usePageRead 处理身份错误时只清理发起读取时的同一会话，避免迟回错误移除新账号。

本机 Node 24.21.0、pnpm 11.15.1，依赖及公开演示配置检查通过。小程序与测试 TypeScript 检查通过；181 套 / 3661 项离线测试通过；pnpm build:mini:demo 通过（原活动详情 chunk 有 webpack 大小建议）。新增 8 项真实登录适配器配合离线微信替身的恢复测试；同步原 Home 生命周期、退出与灵感返回测试。测试结果不等于真实微信或手机验收。

本轮只改客户端，不需要服务端或数据库更新。尚未用本次改动生成手机新预览、替换体验版或正式发布。设备验收：直接进入首页应自动出现本人状态；关闭重开复用会话；失效后自动恢复；断网显示重试；主动退出后重开不自动登入；从分享入口打开活动仍保留目标及原草稿。核对过程中不需要创建或批准业务记录。
