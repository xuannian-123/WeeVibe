# WG05 安排编辑与变更重接受

本分支补齐管理者多环节编辑、预览确认和逐环节重新核实入口。参加记录保留；取消环节保留历史，新增环节不会自动替成员报名。

- 编辑检查活动版本、权限和开始时间，事务内处理环节排序、主环节切换、历史与幂等记录。
- 时间、地点、费用、要求等实质变更触发受影响环节重接受；时间衔接改变时包含共享成员所在的后续环节。
- 容量不能低于已占名额。报名截止变化不阻止已有成员重接受；改动不自动成局。
- 时间或地点变化撤销旧核实与预订适用状态。管理者可核实当前版本；这不代表重新预订成功。
- 成员查看完整前后差异后接受；历史链缺失或不一致时停止接受。旧版事件读取保持兼容。
- 新事件进入现有站内消息；不额外发送微信通知。

## 验证

本机通过 209 个测试文件、4009 项测试、类型检查、后端构建及演示配置小程序构建。小程序构建有体积建议警告。

`scripts/check-wg05-postgres.ts --fixture-only` 在 CI 隔离 PostgreSQL 中验证名额保留、历史链、幂等、权限、跨环节影响、取消及事务回滚。本机数据库受运行环境限制，未冒充通过真实数据库验收；以本分支 CI 结果为准。

未部署共享后端，未替换体验版，未执行本轮手机验收。维护者需在复核合并后部署匹配后端，再验证小程序编辑与成员重接受流程。
