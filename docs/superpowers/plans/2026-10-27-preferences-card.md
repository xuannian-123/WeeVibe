# 偏好卡片实施计划

目标：将默认入局流程改为确认卡片，私聊和刷店作为可选补充。沿用现有 Next.js、组件样式、成员身份和隐私防火墙。

设计：卡片展示参与意愿、出发地、候选日期、可出发时间、最晚到家时间、预算与忌口。档案预填可修改并明确提示；无档案时展示活动默认值，出发地必须本人选择。默认一次确认即完成，不生成刷卡偏好。用户也可选择继续刷店。复杂顾虑通过可展开的私聊提交，仅歧义硬约束需要回问。

采用现有 chat API 增加结构化确认动作，避免新建重复接口或修改共享数据类型。保留原聊天视图以兼容已开始的对话和演示。结构化更新不再把生成的中文摘要交给模型二次解析。
